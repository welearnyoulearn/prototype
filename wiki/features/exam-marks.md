## What it does

Create exams, collect marks from teachers, review, release, and let parents acknowledge.

## Who uses it

School admin (create/review/release), teachers (enter marks), students and parents (results).

## How it works

- Admin creates an exam for a class, adds subjects with maximum marks.
- Teachers enter marks per subject and submit; the admin reviews, can reopen a subject, then **releases** results.
- Students see marks; parents see results and can **acknowledge** them; the admin sees who has not (nudge parents).
- A scheduled job updates exam statuses.

## Rules and limits

- One shared grading ladder (`lib/examGrading.ts`) so a score shows the same grade everywhere.
- Pass mark is set per exam.
