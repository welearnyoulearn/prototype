## What it does

One place to download the school's records as Excel or CSV. Exports only — imports stay where they are (student and staff onboarding, teacher marks entry).

## Who uses it

School admin / principal / vice principal.

## How it works

The screen is generated from a catalog (`lib/dataExport/registry.ts`): each export has a label, the plan feature it needs, its filters and how it builds its table. A school sees only the exports for the modules it has. Groups:

- **People:** student list (grade / section / active, graduated, left), class roll list, parent contact list, staff list.
- **Academics:** classes, subjects per class, exam schedule, exam results (all subjects, total, %, pass/fail), syllabus progress, past-year class history. Report cards are printed from the Report cards tab.
- **Attendance:** class register, daily absentee list (with parent phones), monthly summary per class, low-attendance list — all using the shared attendance rules (holidays excluded, late = attended).
- **Fees:** fee structure, fee ledger, defaulters, payment register (cancelled receipts included with reason), day collection by payment mode, waivers.
- **Expenses:** expense register and totals by category.
- **Calendar & notices:** holidays and events, announcement history with seen / acknowledged counts.
- **Backup:** one Excel workbook with a sheet per module the school uses.

Each card has its own filters (class, exam, academic year, dates, month…) with sensible defaults, a CSV / Excel toggle and a Download button. The **Recent exports** tab lists who downloaded what and when.

## Rules and limits

- CSV files open safely in Excel (formula characters neutralised) and read Telugu / Hindi names correctly (UTF-8 with BOM). Excel files have a header row, frozen header and numeric cells.
- The school comes from the login; a class or exam of another school is "not found". Teachers, students, parents and other schools cannot export.
- Every download is recorded (who, what, filters, rows) because exports contain personal data. Refused requests are not recorded.
- More than 100,000 rows in one file is refused — narrow the filters.
- Not built: PDF exports, scheduled / emailed reports, per-column selection.
