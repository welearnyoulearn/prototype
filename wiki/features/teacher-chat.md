# Feature: Teacher Chat

**Platform Admin feature key:** `teacher-chat`
**Portal:** School Admin / Teacher / Student / Parent
**Status:** Phase 1 built (#558), not yet piloted. The feature key is seeded OFF at every tier. Real students must not use it until the lawyer and counsellor reviews (#557) are done.
**Last updated:** 2026-11-28

---

## What it does

A student asks a teacher any doubt in a chat. Their parents can read every message. It sits beside the quiz doubts ([student-doubts.md](student-doubts.md)), which are unchanged, and does not need the Daily Quiz.

## How it works

- **Who can use it:** the school opens chat class by class. A student also needs a linked parent account. Without either, earlier chats stay readable but nothing new can be sent.
- **Routing:** the subject teacher (`class_subjects`), else the class teacher. The teacher is looked up each time, so a new subject teacher takes over the chats.
- **Student → Ask your teacher:** pick a subject and write. 3 chats waiting at a time, 30 messages a day, 1,000 characters a message.
- **Teacher → Teacher Chat:** longest-waiting first. Reply (2,000 characters), then **Mark answered**.
- **Closing:** the student taps **I understand now** (closed) or **Still not clear**. An answered chat closes after 7 days. A moved student's earlier chats are read only.
- **Ticks:** clock (not saved yet, retried), ✓ saved, ✓✓ the other side's app fetched it, blue ✓✓ they had it on screen. Parent and school reading changes no tick. Open chats refresh every 5 seconds.
- **Parent → Teacher Chats:** read only, per child, with **Report to school**.
- **School Admin → Teacher Chat** (school admin and principal): class switches, open reports, flagged chats, hide a message, close a report. Every chat opened is logged.

## Safety

- Phone numbers, email addresses, 12-digit ID numbers and links are refused, for students and teachers.
- Self-harm wording is delivered, shows the student helpline numbers, and alerts the school. Other worrying wording is marked for school review. The word lists are the ones used by Student Search and are not a full content filter.
- Users cannot edit or delete messages. A hidden message disappears for the student and teacher; the parent and school still see it.
- Notifications never contain message text.
