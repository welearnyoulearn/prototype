WLYL SYLLABUS EXTRACTION — JSON FORMAT FOR AI TOOLS
=====================================================
Copy this whole file and paste it as an instruction to the AI tool you use to
extract a syllabus from a textbook/handbook/workbook PDF. It tells the AI
exactly what JSON shape to produce so it imports cleanly into the WLYL
platform-admin "Import folder" tool with no manual fixing.

ONE JSON FILE PER PHYSICAL BOOK
--------------------------------
Produce one JSON file per book (e.g. one for the Term 1 Textbook, one for the
Term 2 Textbook, one for the Teacher's Handbook, one for the Workbook — even
if they're for the same subject). Do not merge multiple books into one file.

TOP-LEVEL SHAPE
----------------
{
  "book": "<the book's title, exactly as printed on its cover>",
  "book_type": "textbook" | "handbook" | "workbook",
  "audience": "teacher" | "student" | "both",
  "units": [ <unit>, <unit>, ... ]
}

- "book"      — REQUIRED. The book's actual title (e.g. "Second Language
                Telugu", "Telugu Parimalam", "NCERT Democratic Politics
                Part 1"). This is what tells two different books of the same
                type apart, so use the real, specific title — never a generic
                placeholder like "Textbook" or "Part 1".
- "book_type" — REQUIRED. Exactly one of: textbook, handbook, workbook.
- "audience"  — OPTIONAL. teacher, student, or both. If omitted, handbooks
                default to teacher and everything else defaults to student —
                only set this if the book explicitly says otherwise.
- "units"     — REQUIRED. The book's chapters, in the order they appear in
                the book. See below for what belongs at this level.

UNIT SHAPE (recursive)
------------------------
Each entry in "units" (and in a unit's own "subtopics") looks like:

{
  "title": "<the heading text, exactly as printed>",
  "page": <page number the heading starts on, if known>,
  "subtopics": [ <unit>, <unit>, ... ]
}

- "title"     — REQUIRED. The heading text as printed in the book. Keep the
                original numbering prefix if the book has one (see below).
- "page"      — OPTIONAL. The printed page number the section starts on.
- "subtopics" — OPTIONAL. Nest a heading's own sub-sections here, recursively,
                exactly as they're indented/nested in the book's table of
                contents. Omit it (or use an empty array) for a heading with
                nothing under it.

WHAT COUNTS AS A TOP-LEVEL UNIT (chapter) vs. A NESTED SUBTOPIC
-------------------------------------------------------------------
This is the part extraction tools most often get wrong — get this right and
the import needs zero manual cleanup.

A heading belongs directly in the outer "units" array ONLY if it is a real
chapter/unit boundary. Recognizable chapter-heading styles:
  - "Chapter 3 ..." / "Chapter III ..." (word "Chapter" + a number, digits or
    roman numerals)
  - "Unit 5 ..." / "UNIT -5 ..." (word "Unit" + a number, hyphen optional)
  - "3. Title" or "3.Title" (a single number, then a period, then the title —
    NOT a number with a second segment like "3.2")
  - "3 Title" (a bare number then a space, no period at all)

A heading is NOT a new chapter — nest it inside the PRECEDING chapter's
"subtopics" instead — if either of these is true:
  - It's numbered with two or more segments, e.g. "3.2 Features of
    Democracy" or "4.3.1 Types of Change" — that's topic-level numbering
    that belongs nested under chapter 3 (or 4), not sitting next to it.
  - It has no numbering AND no content of its own under it in the book (i.e.
    it would end up with an empty "subtopics") — that's almost always a
    sub-heading of whatever chapter came right before it, not a chapter in
    its own right.

A heading with NO numbering but WITH its own real content underneath (e.g. a
named reader section like "BEEHIVE" or "Supplementary Reader" in an English
book, or a labelled block like "Bhag I" in a combined-language book) DOES
stay as its own top-level unit — don't swallow real sections just because
they aren't numbered.

When in doubt: walk the book's actual table of contents / heading hierarchy
top to bottom, and mirror its nesting exactly — don't flatten everything to
one level and don't invent structure that isn't in the book.

FULL EXAMPLE
-------------
{
  "book": "NCERT Democratic Politics Part 1",
  "book_type": "textbook",
  "audience": "student",
  "units": [
    {
      "title": "Chapter 1 What is Democracy? Why Democracy?",
      "page": 1,
      "subtopics": [
        { "title": "1.1 What is Democracy?", "page": 2, "subtopics": [] },
        { "title": "1.2 Features of Democracy", "page": 4, "subtopics": [] },
        { "title": "1.3 Why Democracy?", "page": 8, "subtopics": [] }
      ]
    },
    {
      "title": "Chapter 3 Constitutional Design",
      "page": 25,
      "subtopics": [
        { "title": "3.1 Democratic Constitution in South Africa", "page": 26, "subtopics": [] },
        { "title": "3.2 Why Do We Need a Constitution?", "page": 29, "subtopics": [] }
      ]
    },
    {
      "title": "Supplementary Reader: BEEHIVE",
      "page": 40,
      "subtopics": [
        { "title": "The Fun They Had", "page": 41, "subtopics": [] },
        { "title": "The Sound of Music", "page": 48, "subtopics": [] }
      ]
    }
  ]
}

Notes on the example:
- "1.1", "1.2", "1.3" are nested under Chapter 1 (multi-segment numbering).
- "3.1", "3.2" are nested under Chapter 3, not under Chapter 1 — each
  chapter's sub-numbering only nests under the chapter it actually follows.
- "Supplementary Reader: BEEHIVE" has no number, but it has real content of
  its own, so it stays as its own top-level unit rather than being folded
  into Chapter 3.

OUTPUT RULES
-------------
- Output ONLY the JSON — no explanation, no markdown fences, no commentary.
- Valid JSON: double-quoted keys/strings, no trailing commas, no comments.
- Use the book's own heading text verbatim — don't paraphrase or renumber.
- Do not generate quiz questions, exercises-as-content, or any assessment
  material — titles/headings only.
